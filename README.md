# Rep Pilot

A workout and fitness log and coach for iOS, with an Apple Watch companion for live in-workout logging.

## What it does

- **Log workouts** manually, or import them automatically from Apple Health (runs, rides, swims, etc. recorded by other apps or devices).
- **Live workout logging on Apple Watch** — start a workout from your wrist across 25 activity types (Weight Training, Running, Cycling, Yoga, HIIT, and more). Weight Training gets a dedicated set-by-set logging flow (exercise → reps/weight per set); other types are simple start/stop sessions.
- **GPS tracking on the Watch** for outdoor activity types (Running, Cycling, Walking, Hiking, Dancing) — records route, distance, and pace via HealthKit, and writes heart rate / calories / distance back to Apple Health as first-class data.
- **Progress tracking** — cardio/strength/mobility scoring per activity, trends over time, body weight log.
- **Planning & coaching** — a weekly planner and rule-based (offline) coaching suggestions.
- Everything is stored locally on-device via SwiftData — no account, no backend, no data leaves the device except to/from Apple Health.

## Architecture

- **`RepPilot/`** — the iOS app (SwiftUI + SwiftData, iOS 17+).
- **`RepPilotWatch/`** — the watchOS companion (watchOS 10+), runs independently of the phone (`WKRunsIndependentlyOfCompanionApp`).
- **`RepPilot/Shared/`** — code shared by both targets (the watch-to-phone wire payload, the watch workout-type catalog).
- Watch ↔ phone sync goes over `WatchConnectivity` (`transferUserInfo`), with a durable retry queue on both sides — see `Services/Connectivity/` (phone) and `Services/WatchOutboxStore.swift` (watch). Neither side needs the other reachable at the moment a workout ends; delivery and retry happen automatically when they reconnect.
- SwiftData schema is versioned (`Services/Migrations/`) — see that folder's doc comments before changing any `@Model` type.
- Project files are generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` — run `xcodegen generate` after editing it or after adding/removing source files, then reopen `RepPilot.xcodeproj`.

## Building

```sh
xcodegen generate
xcodebuild -scheme RepPilot -destination 'generic/platform=iOS Simulator' build
xcodebuild -scheme RepPilotWatch -destination 'generic/platform=watchOS Simulator' build
```
